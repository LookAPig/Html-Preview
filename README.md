# TESWAY 官网 · UI 设计规范

> 品牌口号：**Go Far Away!**　关键词：长续航 · 双电机 · 户外 · 自由。
> 视觉基调：**浅灰底 + 黑白主体 + 单一橙色点睛**，大字号英文标题制造速度感，动效克制但到位。
> 技术栈：纯 HTML / CSS / JS，无构建；所有设计变量定义在 `css/base.css` 的 `:root`。

---

## 1. 颜色

**只用三色：橙 `#FE5416`、黑 `#222222`、白 `#FFFFFF`**，其余均为它们的透明度变体。禁止引入新的色相（蓝、绿、紫等）。

| 变量 | 值 | 用途 |
|---|---|---|
| `--volt` | `#FE5416` | 品牌橙：强调词、价格标签、进度、激活态、徽标点 |
| `--text` | `#222222` | 主文字、主按钮底色、深色卡片 |
| `--bg` | `#FFFFFF` | 卡片、抽屉、弹层、页脚 |
| `--page` | `#F6F6F6` | 页面主背景（与白色页脚形成层次） |
| `--bg-2` / `--bg-3` | `#F5F5F5` / `#EBEBEB` | 次级填充、输入框、进度轨道 |
| `--muted` | `rgba(34,34,34,.62)` | 辅助说明文字 |
| `--line` | `rgba(34,34,34,.08)` | 分割线、卡片描边 |

**使用比例**：灰/白 ≈ 70%，黑 ≈ 25%，橙 ≤ 5%。橙色是"信号色"，一屏内只出现在 1–3 个关键点上。

- 标题中强调词用 `<em>`：橙色 + `skewX(-8deg)` 倾斜（见 `.sec-head em`）。
- 删除价 / 次要说明：`rgba(34,34,34,.4)`；白底上的说明：`rgba(34,34,34,.45)`。
- 图片上的文字：白色 + 底部黑色渐变遮罩 `linear-gradient(transparent → rgba(34,34,34,.5~.8))`。
- 橙色发光仅用于进度/激活：`box-shadow: 0 0 .75rem rgba(254,84,22,.45)`。

## 2. 字体

| 变量 | 字体 | 用途 |
|---|---|---|
| `--font-en` | **Anton**（备选 Impact / Arial Black） | 大标题、数字、产品大字、口号，**一律大写** |
| 正文 | **Inter** 400 / 600 / 800 | 正文、按钮、标签、导航 |
| `--font-cn` | PingFang SC / HarmonyOS Sans SC / 微软雅黑 | 中文回退 |

### 字号阶梯（rem，自动随屏幕缩放）

| 层级 | 移动端 | 桌面端 | 规则 |
|---|---|---|---|
| 超大展示字（页脚口号 / 品牌大字） | 4.5 | 7–13 | Anton，可 JS 撑满宽度 |
| 模块标题 `.sec-head h2` | 2.25 | 4 | Anton，行高 1–1.05，`text-wrap: balance` |
| 卡片大标题 | 1.5–2 | 2–3.5 | Anton 或 Inter 800 |
| 小标题 / 卡片标题 | 0.9375–1.125 | 1–1.375 | Inter 700–800，字距 -.01em |
| 正文 / 副标题 `.sec-sub` | 0.875–0.9375 | 0.9375–1 | Inter 400，行高 1.5–1.6，颜色 `--muted` |
| 按钮 | 0.8125 | 0.875 | Inter 600 |
| 辅助 / 元信息 | 0.6875–0.75 | 0.75–0.8125 | Inter 400–600 |
| 眉标 `.eyebrow` | 0.75 | 0.75 | Inter 600，大写，字距 `.24em` |

- 最小字号 **0.5625rem**（仅限支付标识等装饰），正文不小于 0.75rem。
- 价格、计数、百分比使用 `font-variant-numeric: tabular-nums`，避免跳动。
- 价格主数字：Inter 800，字距 `-.03em`。

## 3. 尺寸与适配

**移动端优先**：默认样式即手机样式，桌面覆盖写在 `@media (min-aspect-ratio: 1/1)` 中（横屏即桌面布局）。

**rem 等比缩放**（所有尺寸用 rem，不用 px）：

```css
html { font-size: calc(min(100vw / 390, 100svh / 844) * 16); }          /* 设计稿 390×844 */
@media (min-aspect-ratio: 1/1) {
  html { font-size: calc(min(100vw / 1440, 100vh / 900) * 16); }       /* 设计稿 1440×900 */
}
```

即：按设计稿 px ÷ 16 = rem。例：设计稿 44px 按钮 → `2.75rem`。

| 变量 | 移动端 | 桌面端 | 说明 |
|---|---|---|---|
| `--pad` | 1.25rem | 3.5rem | 页面左右边距 |
| `--sec-y` | 6.25rem | 12.5rem | 模块上下间距 |
| 导航高度 | 4rem | 4rem | `scroll-padding-top: 4rem` |

- 间距优先使用 4 的倍数：`0.25 / 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 / 2.5rem`。
- 安全区：底部悬浮元素加 `env(safe-area-inset-bottom)`。
- 触控目标 ≥ 2.75rem（44px）。

## 4. 布局

- 每个模块 = `<section>` + `.sec-head`（眉标 `.eyebrow--dot` → `h2` 含 `<em>` → `.sec-sub`）+ 内容区。
- 全局规则 `section { padding: var(--sec-y) var(--pad) 0 }`，**弹层 / 抽屉内部禁止使用 `<section>`**，用 `<div>`。
- 移动端：单列纵向；横向内容用 scroll-snap 横滑（卡片宽 ~82%，露出下一张提示可滑动），隐藏滚动条。
- 桌面端：常用 2 列（左文案 / 右视觉）或 4 列网格；长内容可做 sticky 吸顶滚动叙事（`.hot`、`.film`）。
- 层级（z-index）：导航 50 → 右下工具栏 45 / 滚动条 55 → 进度条 60 → 弹窗 80 → 购物车 90 → 搜索 92 → 加载页 100。

### 圆角

| 变量 | 值 | 用途 |
|---|---|---|
| `--r-sm` | 0.5rem | 标签、小缩略图 |
| `--r-md` | 0.75rem | 列表项、输入框、小卡片 |
| `--r-lg` | 1rem | 大卡片、图片、弹层 |
| `--r-pill` | 999px | 按钮、胶囊标签、开关 |

### 阴影

- 卡片悬浮：`0 .75rem 2rem -.5rem rgba(34,34,34,.22)` + `0 0 0 1px var(--line)` 描边。
- 弹层：`0 1.5rem 3rem -1rem rgba(34,34,34,.28)`。
- 不使用纯黑或大范围硬阴影。

## 6. 图片规范

| 类型 | 目录 / 格式 | 比例 | 要求 |
|---|---|---|---|
| 首屏 Banner | `Images/hero-*.jpg`，PC 与移动端（`-m`）各一张 | PC 16:9 / M 9:16 | 主体偏右（PC）或偏下（M），左侧 / 上方留白放文案 |
| 产品白底图 | `Images/hot/*.webp`（含 `-frame` 线稿版） | 4:3 | **纯白或透明底**、正侧面、车头朝左，配合 `mix-blend-mode: multiply` 融入灰底 |
| 产品场景图 | `Images/bike-*.jpg` | 1:1 / 4:3 | 用于购物车、搜索缩略图 |
| 场景 / 故事图 | `Images/scenes/`、`story-*.jpg` | 3:4 竖图 | 真实户外骑行，人物 + 车，自然光（晨昏暖色最佳） |
| 视频 | `Images/hero.mp4` | 16:9 | 静音循环，`playsinline`，进入视口才加载 |

- **风格**：真实摄影、低饱和自然色、晨昏暖光；避免过度修图、强滤镜、杂乱背景。车身以黑色为主，与橙色点缀呼应。
- **体积**：照片 ≤ 400KB，产品透明图优先 WebP ≤ 100KB；视频 ≤ 10MB。
- **加载**：首屏图正常加载，其余一律 `loading="lazy" decoding="async"`；视频用 `data-src` 懒加载。
- **裁切**：容器定比例（`aspect-ratio`）+ `object-fit: cover`，禁止拉伸变形。
- **交互**：hover 缓慢放大 `scale 1.04–1.08`（.6–1.2s），收起状态可去饱和 / 压暗。
- **无障碍**：内容图写英文 `alt`，纯装饰图 `alt=""`。

## 7. 动效

| 变量 / 曲线 | 值 | 用途 |
|---|---|---|
| `--ease` | `cubic-bezier(.2,.8,.2,1)` | 默认缓出：入场、hover |
| 幕布 | `cubic-bezier(.76,0,.24,1)` | 面板展开 / 收起、加载页退场 |
| 展开 | `cubic-bezier(.65,0,.15,1)` | 手风琴、宽度变化 |
| 回弹 | `cubic-bezier(.34,1.4,.64,1)` | 悬浮工具出现等轻量弹性 |

- **时长**：微交互 .2–.3s；元素入场 .6–.9s；大面板 / 幕布 .7–.9s。
- **入场**：`.reveal` 从下方 2.5rem 淡入，`data-delay="1~3"` 错峰 .1s。
- **列表错峰**：子项依次延迟 .05–.08s。
- **只动画 `transform` / `opacity` / `clip-path`**，避免动画 `width/height/top`。
- 必须尊重 `prefers-reduced-motion: reduce`（`base.css` 已全局降级）。
- 悬停意图：易误触的大面积 hover 切换需延迟（如场景手风琴 320ms）。

## 8. 文案语气

- 英文为主，短句有力：`Two motors. Every road, every weather.`
- 标题 2–4 个词，结尾词用 `<em>` 橙色强调：`Built To <em>Go Far</em>`。
- 数字具体可感：`160 km range`、`120 N·m`、`2-year warranty`。

## 9. 开发约定

- 单文件 ≤ 199 行，超出拆分（如 `foot.css` / `foot-fx.css` / `foot-acc.css`）。
- 数据与视图分离：`xxx-data.js`（`window.TESWAY_XXX`）+ `xxx.js`（IIFE 渲染与交互）。
- 类名 BEM 风格：`.block__elem`、`.block--mod`、状态 `.is-open / .is-on / .is-hide`。
- 本地预览：`npx -y http-server -p 5173 -c-1`；生成长图：见 `tools/preview-shot.js`。
